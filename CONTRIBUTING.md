# Contributing to Saath

Thank you for wanting to help! Saath stays simple, kind and trustworthy, so please follow these few rules.

## 🌐 Add a translation

1. Copy [`README.md`](README.md) into `translations/<language-code>.md` (for example `translations/es.md` for Spanish or `translations/ta.md` for Tamil).
2. Translate it in simple, everyday words. A natural translation is better than a word-for-word one.
3. Add your language to the **"Read in"** line at the top of `README.md`.
4. Open a pull request.

## 📞 Add a helpline

Only add helplines run by a **government body, hospital, university or registered non-profit**. In your pull request, include a link to the official page that shows the number and hours.

## ✏️ Improve the wording

Spotted something confusing, unkind or wrong? Open an issue or a pull request.

## 🚫 Please don't

- Share personal stories or problems in issues or comments. GitHub is public, and no one here is a trained counsellor.
- Add paid services, ads, or links you haven't checked.
- Add medical claims or treatment advice.
